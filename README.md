# LastHitCommander

Moba inspired tactics and precision video game developed on Godot engine.

Добивать крипов, будучи полководцем на поле боя: за ласт-хиты прокачиваешь армию или себя, выиграть одно сражение а-ля 2048

Godot 4.4. Проект Godot лежит в `lasthitcommander/`: открыть `lasthitcommander/project.godot` в редакторе, запуск F5.
