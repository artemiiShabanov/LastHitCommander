# Last H!t: GDD

## Одной фразой

Добивать крипов, будучи полководцем на поле боя: за ласт-хиты прокачиваешь армию или себя, выиграть одно сражение а-ля 2048

## Идея

- Добивать именно крипов (last hit), будучи полководцем на поле боя.
- За ласт-хиты прокачиваешь либо свою армию, либо себя.
- Цель: победить в сражении один раз, а-ля 2048: одна партия до победы.
